1. TẠI SAO MANG SANG MÁY KHÁC BỊ LỖI TRƯỚC ĐÂY? (ĐỂ TRÁNH LẶP LẠI)
--------------------------------------------------------------------------------
- File "LongATTest.bat" gọi trực tiếp "LongATTest.exe" (.NET 8 WPF).
- Máy tính mới thường CHƯA CÀI:
  + Microsoft .NET 8.0 Desktop Runtime (x64)
  + Microsoft Edge WebView2 Runtime
- Do đó máy mới sẽ không chạy được file .exe dù máy đó đã cài sẵn Python.
- GIẢI PHÁP ĐÃ TÍCH HỢP SẴN:
  + Muốn chạy Python ngay: Nhấp đúp vào [ Run_Python.bat ]
  + Muốn chạy bản .exe chuẩn: Nhấp đúp vào [ Start_Tool.bat ] (tự động tải .NET)

--------------------------------------------------------------------------------
2. BẢN ĐỒ CẤU TRÚC DỰ ÁN (CẦN SỬA GÌ THÌ VÀO ĐÂU?):
--------------------------------------------------------------------------------
📁 web/                          -> GIAO DIỆN CHÍNH (HTML, CSS, JS)
   ├── index.html                - Giao diện 8 module test & sidebar
   ├── styles.css                - Giao diện Cyber Dark, bo góc, hiệu ứng led
   ├── app.js                    - Logic test Loa, Mic, Camera, Canvas, Phím
   └── logo.png                  - Logo hình tròn trong suốt khử răng cưa

📁 scripts/                      -> ENGINE ĐỌC PHẦN CỨNG (POWERSHELL)
   ├── get_specs.ps1             - Đo CPU, RAM hãng/bus, GPU VRAM 12GB+, NVMe/HDD
   ├── get_battery.ps1           - Đo dung lượng pin thiết kế/thực tế, độ chai
   ├── get_thermal.ps1           - Đo nhiệt độ phần cứng
   └── stress_cpu.ps1            - Tạo tải quạt tản nhiệt

📁 LongAT_App/                   -> ỨNG DỤNG STANDALONE NATIVE (.NET 8 C# WPF)
   ├── MainWindow.xaml / .cs     - Cửa sổ ứng dụng, khởi tạo WebView2
   ├── KeyboardHook.cs           - Hook bàn phím tầng thấp bắt F1-F12 không vướng F12 DevTools
   ├── LocalServer.cs            - Máy chủ HTTP REST API nội bộ bằng C#
   ├── HardwareEngine.cs         - Cầu nối gọi scripts PowerShell
   └── app.ico                   - Icon ứng dụng đa kích thước

🐍 server.py                     -> MÁY CHỦ PYTHON THUẦN (FALLBACK SERVER)
   - Chạy độc lập, chỉ dùng thư viện chuẩn của Python (không cần pip install)
   - Tự động mở cửa sổ Edge/Chrome native app (--app=http://127.0.0.1:8765)

🚀 CÁC FILE CHẠY NHANH:
   ├── Start_Tool.bat            - Khởi động tự động (tự tải .NET & thư viện nếu thiếu)
   ├── Run_Python.bat            - Khởi động 1-click bằng Python
   └── installer.iss             - Script tạo bộ cài đặt Windows Setup.exe bằng Inno Setup

4. CÁCH "VIBE CODING" SIÊU NHANH TRÊN MÁY TÍNH MỚI:
--------------------------------------------------------------------------------
Bước 1: Mở thư mục code trên máy mới bằng VS Code / Cursor / Sublime Text.

Bước 2: Muốn sửa giao diện hoặc thêm nút mới:
  - Mở "web/index.html" thêm thẻ HTML.
  - Mở "web/styles.css" chỉnh màu sắc, kích thước.
  - Mở "web/app.js" viết hàm xử lý sự kiện.
  - Mẹo test nhanh (Hot-reload): Nhấp chạy "Run_Python.bat", ra trình duyệt nhấn F5
    là thấy ngay kết quả sửa, KHÔNG CẦN BIÊN DỊCH LẠI!

Bước 3: Muốn sửa logic đo phần cứng:
  - Mở thư mục "scripts/" sửa file "get_specs.ps1" hoặc "get_battery.ps1".
  - Test trực tiếp bằng lệnh PowerShell:
    powershell -ExecutionPolicy Bypass -File scripts\get_specs.ps1
  - Cả C# lẫn Python đều tự động nhận thông số mới ngay lập tức!

Bước 4: Đóng gói lại thành file .exe sau khi code xong:
  Mở PowerShell trong thư mục này và gõ:
    dotnet publish LongAT_App/LongATTestApp.csproj -c Release -o publish /p:PublishSingleFile=true /p:SelfContained=false
    Copy-Item "publish\LongATTest.exe" -Destination "LongATTest.exe" -Force

Bước 5: Đẩy code mới lên GitHub:
    git add .
    git commit -m "feat: cap nhat tinh nang moi"
    git push origin main
